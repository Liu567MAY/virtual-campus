# Virtual Campus

3D virtual campus project with a Vue 3 + Three.js frontend, Spring Boot backend, FastAPI AI service, and supporting database/deployment assets.

## Project Structure

- `frontend/`: Vue 3 + Three.js client
- `backend/virtualCampus/`: Spring Boot business service
- `ai-service/`: FastAPI + LangGraph AI service
- `database/`: schema initialization and migrations
- `assets/`: source art, textures, Blender files, and references
- `deploy/`: deployment configuration
- `docs/`: product, architecture, database, and API documentation
