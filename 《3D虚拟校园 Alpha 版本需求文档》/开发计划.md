# 开发计划


# 第一阶段：基础3D环境（第1周）

目标：

完成Vue3 + Three.js基础环境。


任务：

- Vue3 + TypeScript项目搭建
- Three.js基础场景
- WebGL渲染验证
- 基础摄像机控制
- 玩家移动


阶段成果：

用户可以通过浏览器进入3D校园基础场景，并控制角色移动。


---

# 第二阶段：校园探索（第2周）

目标：

完成校园核心区域探索体验。


任务：

- 加载低多边形校园建筑模型
- 完成校园入口、教学楼、图书馆、食堂和宿舍区域
- 建筑信息展示
- 建筑交互
- AI学长NPC展示
- Spring Boot与PostgreSQL基础能力
- 创建基础用户身份
- 创建简单虚拟角色
- 查看其他新生角色及基础信息


阶段成果：

用户可以通过虚拟角色探索校园、查看建筑信息，并看到AI学长和其他新生角色。


---

# 第三阶段：AI能力（第3周）

目标：

完成AI学长校园问答闭环。


任务：

- Spring Boot转发AI请求
- FastAPI AI服务
- LangGraph AI学长Agent
- 校园知识文档整理与切片
- pgvector向量检索
- RAG校园知识库
- AI学长问答
- 对话记录保存


阶段成果：

用户可以向AI学长提问，并获得基于校园知识库的回答。


---

# 第四阶段：体验完善与展示（第4周）

目标：

形成可展示版本。


任务：

- UI优化
- 交互优化
- 加载性能优化
- 优化NPC Prompt
- 优化RAG回答质量
- 用户行为记录
- 用户反馈功能
- Docker部署
- Nginx配置
- 线上测试
- Demo视频
- 项目文档


阶段成果：

完成可用于展示和测试的 MVP 版本。
